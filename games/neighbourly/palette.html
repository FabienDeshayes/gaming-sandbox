The palette

The 32 colours everything is drawn in, in ramps from dark to light. Change a colour and every sprite below and every role the game gives it follows at once; export the file when you like it. A colour's one-letter key is what a sprite is written in, and its name is what src/config.js calls it, so both stay put: only the colour moves. Unsaved changes are kept in this browser.
