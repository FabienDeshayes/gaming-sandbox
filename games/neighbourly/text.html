Every word

Every string in src/text.js, read from the file itself, under the part of the game it belongs to. Edit any of them; export rebuilds the file with your strings put back where they were and every other byte (code, comments, the numbers spliced into a sentence) untouched, so an export with no edits is the file on disk. Under each string is the line it sits on: a ${…} there is a number or a word the game fills in, so keep the sentence around it. Unsaved edits are kept in this browser.
