# Nouxinha — one campaign, in pictures

One save slot played from NEW GAME to the credits with **cheats off**: five worlds out of the same slot, all four kinds of world finished, every colour carried home in each of them. 101 screenshots of the moments that make it up.

The walk behind these was driven through the test harness (`tests/harness.js`) — real key presses into the real canvas, routes worked out by asking the game's own pure functions where things are. Nothing in `src/` was changed to take them.

| World | Kind | Seed | Finished it |
|---|---|---|---|
| 1 | frozen | `-2112801752` | yes |
| 2 | temperate | `-686578983` | yes |
| 3 | desert | `322061385` | yes |
| 4 | temperate (again) | `1097562759` | nothing new — the kind was already behind him |
| 5 | mystic | `-1054577747` | yes — and the end of the game |
